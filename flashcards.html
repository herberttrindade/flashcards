Deck import format

Only front and back are required. Everything else is optional and falls back to a default.

CSV

First row must be a header with column names (any order). Wrap a field in quotes if it contains a comma or line break.

front,back,meaning,example,level,type
"What does ""break the ice"" mean?",Break the ice,"To ease tension in a social setting","He told a joke to break the ice.",B2,Idiom
Bonjour,bonjour,hello (informal),"Bonjour, ça va?",A1,French

JSON

Either a bare array of cards, or an object like the bundled deck files ({"cards": [...]}). This includes files like the bundled english_grammar_tenses.json — any JSON with a cards array full of front/back objects imports the same way.

{
  "cards": [
    {
      "type": "French",
      "front": "Bonjour",
      "back": "bonjour",
      "meaning": "hello (informal)",
      "example": "Bonjour, ça va?",
      "level": "A1"
    }
  ]
}

Grammar-style cards work the same way — type, front, back, meaning, example and level are read exactly as above; any extra fields (like the bundled Grammar deck's tense and context) are simply ignored on import.

{
  "cards": [
    {
      "type": "Grammar",
      "tense": "Second Conditional",
      "context": "Coffee shop",
      "front": "Fill in: If I _____ (own) a café, I _____ (serve) only fair-trade coffee.",
      "back": "If I owned a café, I would serve only fair-trade coffee.",
      "meaning": "An unreal, hypothetical present situation uses second conditional.",
      "example": "If I had more time, I would learn how to make latte art.",
      "level": "B2"
    }
  ]
}

Field reference

front — required, the question side.
back — required, the answer side.
meaning / example — optional, shown on the back of the card.
level — optional, one of A1/A2/B1/B2/C1/C2 (defaults to B1).
type — optional, the deck/category name. Rows without it can share one deck name you're asked for at import time. Include a type per row/entry to split one file into several decks at once.
Any other fields (e.g. tense, context) are accepted in the source file but not imported — only the fields above are used.

Cards that already exist (same deck + front + back as one already in your library) are skipped automatically, so re-importing the same file is safe.

How to read a card

A quick guide to every number, tag, and stat you'll see while studying.

Stats at the top

Due now — cards you've studied before that are ready to review again today.
New — cards you haven't studied yet (this also includes cards you just got wrong, since they briefly go back to "relearning").
Mastered — cards you know well, currently scheduled 21+ days out.
Total — how many cards match your current filters (source / deck / level).

Front of the card

Ring with a number (top right, e.g. "12d") — how many days until this card comes up again, based on your last answer. Empty ring = brand new. Full ring = well memorized (30+ days).
Small tag (e.g. "Idiom", "Word") — which deck/category this card belongs to.
Colored badge (A1–C2) — the difficulty level.
Big text in the middle — the question. Tap the card to flip it and see the answer.

Back of the card

Highlighted text — the answer.
Line underneath — what it means.
Text in quotes — an example sentence using it.

The four grading buttons

Again — you didn't remember it; it comes back in about 10 minutes so you can try again.
Hard — you got it, but it took effort; comes back a bit sooner than usual.
Good — normal pace; the regular schedule applies.
Easy — too easy for you; comes back after a much longer gap.
